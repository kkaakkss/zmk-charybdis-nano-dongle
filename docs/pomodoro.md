# OLED 프리셋 타이머

필요한 때 켜는 단발 타이머다. 집중/휴식 자동 반복·회차·일시정지·재개는 제거했다.
기존 USB/BLE·배터리·잠금·수정키·봉고캣·레이어 배치는 유지한다.

## 네 가지 조작

기본 레이어에서 **S+D+F로 OSL을 켜고 키를 놓은 뒤**, 오른손 홈로우의 아래 키를 누른다.
J/K/L/;는 기본 배열의 물리 위치를 뜻한다.

| OSL 키 | 기능 |
|---|---|
| **J** | 지금부터 **5분** 새로 시작 |
| **K** | 지금부터 **10분** 새로 시작 |
| **L** | 지금부터 **25분** 새로 시작 |
| **;** | 강제 종료하고 타이머 UI·점멸을 즉시 없애기 |

진행 중·완료 알림 중에 J/K/L을 누르면 남은 시간과 관계없이 선택한 시간으로 교체한다.
같은 키를 다시 눌러도 일시정지가 아니라 처음부터 다시 시작한다.
이전 W+O/E+I 타이머 콤보는 제거했다. 타이머와 관계없는 기존 50개 콤보는 유지한다.

## 화면과 완료 알림

진행 중에는 `TIMER`와 `05:00` / `10:00` / `25:00`에서 줄어드는 남은 시간을 표시한다.
시간이 끝나면 `DONE` + 작은 축하 얼굴/색종이 픽셀 그림과 `00:00`을 표시한다.
기존 UNSCII 글꼴은 컬러 이모지를 지원하지 않아 `🥳🎉` 대신 직접 만든 단색 8×8 그림 두 개를 쓴다.

1. 완료 후 **20초**: OLED 전체를 0.5초 켜기 / 0.5초 끄기로 점멸한다(초당 한 번).
2. 이후 **1분 추가**: 전체 화면을 켠 상태로 DONE 타이머 UI를 유지한다.
3. 완료 후 **총 80초**가 되면 타이머 UI가 자동으로 사라진다.
   일반 UI로 돌아와도 종료 시점부터 5분까지 화면을 유지한다.

점멸 중에도 키보드·트랙볼 입력을 처리한다. 알림 중 OSL J/K/L은 새 타이머로 즉시 교체하고,
OSL ;는 점멸까지 취소한다. 소리나 PC 알림, 가짜 키·활동 이벤트는 보내지 않는다.

## 절전·전원·배치

평소 5분 무입력 화면 꺼짐은 유지하지만, **타이머 실행 중에는 화면을 끄지 않는다.**
자연 종료 시점부터 5분 동안 완료 알림과 일반 UI를 계속 표시한 뒤 절전으로 복귀한다.
25분 타이머를 시작한 뒤 입력이 없다면 시작 후 30분에 화면이 꺼진다.
완료 후 입력이 있었다면 입력에 따른 기존 5분 무입력 정책이 더 오래 화면을 유지할 수 있다.
강제 종료는 타이머의 화면 유지도 취소하고 일반 무입력 정책으로 즉시 복귀한다.
표시 지연이 있어도 알림과 화면 유지 기한은 실제 종료 시각 기준이며,
가짜 입력·활동 이벤트로 시스템 유휴 시간을 변경하지 않는다.

전원을 끊거나 재부팅하면 타이머는 초기화된다. Flash 저장이나 PC 시간 동기화는 하지 않는다.
USB 절전에서 MCU uptime 자체가 멈추는 경우까지 실제 시각과 일치한다고 보증하지 않는다.

9px 높이의 두 줄은 x=0, y=18/27이다. DONE 축하 그림은 x=38/48, y=19이며
기존 잠금 표시(y=36)와 봉고캣(x=78 이후)을 가리지 않는다. 이전 회차 점은 제거했다.
LVGL 12KiB 힙, 1비트 전체 프레임버퍼, 4096바이트 전용 작업 큐 스택은 유지한다.

## 구현과 검증

- `src/pomodoro_logic.h`: OFF/RUNNING/DONE 모델과 절대 종료 시각.
- `src/pomodoro.c`: 5/10/25/0 네 명령과 중앙 동작. UI 종료까지 주기 작업을 유지한다.
- `widgets/pomodoro.c`: display 전용 큐에서만 LVGL과 전체 화면 blank/unblank 호출.
  고정 ZMK의 `unblank_display_cb`/`blank_display_cb` 어댑터를 쓰므로 ZMK 업그레이드 시 다시 확인한다.
- `scripts/test-pomodoro.py`: 실제 모델·동작·위젯 C를 ARM 또는 호스트 GCC+UBSan으로 검사한다.
  세 프리셋의 2,400초 진행, 교체·동일 시간 재시작·종료, 40개 점멸 반주기,
  20초/80초 경계, 알림 중 입력·유휴 전환·재시작·취소, 지연 콜백과 64비트 uptime을 확인한다.

검사에서 커널·큐·LVGL·디스플레이는 테스트 더블이다. 실물 표시/할당/동시성 검사는 아니므로
화면 겹침·점멸·실제 입력·타이머 중 화면 유지 및 종료 5분 뒤 절전은 실기기로 최종 확인한다. 동글 OLED UF2만 교체하며 좌우 재설치는 필요 없다.
