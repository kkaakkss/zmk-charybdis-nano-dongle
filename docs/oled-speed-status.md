# OLED 현재 속도와 배터리 표시

MOUSE/SCROL/SNIPE/FASTER에서 예전 CPM 영역(x=38,y=0,36×18)에 현재 설정을 표시한다.
모드 전환과 속도 버튼 처리 후 display 전용 큐에서 최신 상태를 읽어 표시한다.
키보드 레이어에서는 이 위젯을 숨긴다. 타이머·봉고캣 배치는 유지한다.

- MOUSE: `eCPI` / 기본 `400`. 일반 배율 적용 값.
- SNIPE: `eCPI` / 기본 `100`. SNIPE 배율 적용 값.
- FASTER: `eCPI` / 기본 `600`. 일반 배율 ×1.5 ×FASTER 전용 배율 적용 값.
- SCROL: `SCR` / 기본 `100%`. 스크롤은 CPI가 아닌 배율로 표시한다.

센서 하드웨어는 400 CPI로 고정이다. eCPI는 소프트웨어 환산 기본 감도이며
순간 이동 속도에 따라 변하는 가속은 숫자에서 제외한다. 따라서 조절 중 숫자가 흔들리지 않는다.
일반 200%·FASTER 200%에서는 eCPI 2400이다. 최댓값도 네 자리(35px) 안에 들어간다.

배터리는 L이 위, R이 아래이며 `L59%`, `R07%`, `L00%`, `R100%`처럼 붙여 표시한다.
기존 컨테이너는 LV_SIZE_CONTENT에 오른쪽 정렬과 -7px 여백을 사용했다.
고정 LVGL의 실제 폭 계산은 44px짜리 라벨을 44px 폭으로 잡아 -7px 여백 때문에
앞 7픽셀을 잘랐다. 앞부분이 공백일 때는 드러나지 않았지만 L/R을 넣으면 글자가 잘렸다.
컨테이너를 51px로 고정해 44px 라벨과 7px 여백/아이콘을 모두 포함하도록 수정했다.
0% 보고도 숨기지 않는다. 초기 배터리 보고를 UI보다 먼저 받았다면 core 캐시를 읽는다.
BLE 슬롯은 좌우가 아니므로 전원 직후에는 ?이며 일반 키 입력으로 L/R을 식별한다.

실제 속도 모델·위젯 C와 고정 LVGL 폭 계산을 회귀 검사한다. LVGL/커널/전송 API는
테스트 더블이며 실물 폰트 렌더링·USB·초기 좌우 식별은 실기기 확인이 필요하다.
