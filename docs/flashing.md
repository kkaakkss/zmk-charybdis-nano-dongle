# 설치, 페어링, 복구

## 먼저 복구 파일 보관

판매자 `20260307-nano35.zip` 원본을 PC에 보관한다. 내부의 왼손/오른손 UF2와
settings_reset은 Nano 복구용이다. 이 ZIP에는 Sofle 동글 복구 이미지가 없다.
동글을 덮어쓰기 전에 **현재 동글에 맞는 기존 UF2**를 기존 Actions artifact 또는
판매자에게서 확보한다. UF2 드라이브의 CURRENT.UF2 제공 여부는 부트로더마다 다르며
항상 읽기 백업이 가능한 것은 아니다. 파일이 없으면 기존 동글 복구 가능성을 보장하지 않는다.
설정 초기화는 키맵/본드를 지운다. 부트로더는 덮어쓰지 않는다.

## 기존 동글 구성을 업데이트할 때

키맵·트랙볼 모드만 갱신할 때는 사용할 동글 UF2(기본/OLED/Studio 중 하나)만 교체합니다.
현재 정상 연결된 좌우 반쪽 재설치나 본드 초기화는 필요하지 않습니다.
정상 동작하던 이전 UF2는 복구용으로 보관합니다.
OLED와 Studio는 별도 동글 빌드이며 합쳐진 파일이 아닙니다.

## 처음 동글 구성을 설치할 때

1. PC의 기존 Nano BLE 페어링을 제거한다. 이전 동글과 반쪽을 모두 끈다.
   초기 페어링 동안 기존 Sofle 등 다른 ZMK split 반쪽도 꺼 두고 신규 세 장치만 켠다.
   기본 ZMK split 서비스 UUID가 같아 초기 검색에서 다른 반쪽을 발견할 수 있다.
2. 각 장치를 **하나씩** USB에 연결하고 reset을 빠르게 두 번 눌러 UF2 드라이브에 진입한다.
   보드가 nice_nano_v2/SuperMini nRF52840 호환 부트로더인지 확인한다.
3. 세 장치 각각에 `nano35-settings-reset.uf2`를 복사하고 재부팅/설정 삭제가 끝나도록
   수 초 기다린다. 드라이브가 사라지는 것은 자동 재부팅일 수 있다. 다시 double-reset한다.
4. 동글에는 `nano35-dongle.uf2`, 왼손에는 `nano35-left.uf2`, 오른손에는
   `nano35-right.uf2`를 복사한다. 세 파일은 같은 빌드의 세트로 사용한다.
5. 동글을 PC USB에 연결한다. 왼손을 켜 연결한 다음 오른손을 켠다. 서로 가까이 둔다.
   센서 초기화에는 추가 1초가 필요하다. split 페어링은 펌웨어가 자동 처리하며 PC에서
   좌우를 직접 BLE 키보드로 페어링하지 않는다.
6. 재연결이 안 되면 세 장치 전부 같은 순서로 초기화 후 재설치한다.
   동글 또는 한쪽의 본드만 지우면 나머지에 이전 키가 남을 수 있다.

## 실물 확인 항목

- OS에서 동글 USB keyboard/mouse HID 인식. 양쪽 USB를 빼고 배터리로도 입력 전달.
- 좌18/우17키를 한 개씩 확인. QWERTY 위치, 엄지 5개, 동시 누름/keyup/수정키 확인.
- 오른손 트랙볼 상하좌우 방향, 작은 움직임, 빠른 회전, 멈춘 뒤 잔여 움직임 확인.
- Mouse/Scroll/Snipe의 3개 버튼 및 drag 확인. 양쪽 키 입력 중에도 포인터가 유지되어야 한다.
- 동글/반쪽 각각 재부팅, USB 재삽입, 10분 유휴 후 입력 복구 확인.
- OLED 선택 파일은 표시 위치/방향/전원과 연결 상태 화면을 확인.
- Studio 선택 파일은 USB 연결 → OSL의 V+P 위치 콤보로 unlock → 35키 편집/저장/재부팅 후 유지 확인.

축이 반대로 움직이면 right.conf의 SWAP_XY/INVERT_X/Y만 실물 결과에 맞게 조정한다.
CPI는 pmw3610.dtsi의 400에서 시작한다. 센서 미동작은 방향 문제가 아니므로 먼저
전원/초기화 지연/SDIO/CS/MOTION 배선을 확인한다. 양쪽 GPIO는 센서와 별개 MCU라서
동글 OLED P0.17/P0.20과 오른손 SPI의 같은 번호는 충돌하지 않는다.

## 판매자 Nano 펌웨어로 복구

동글 전원을 끄고 Nano 두 반쪽을 double-reset한다. 판매자 ZIP의 settings_reset을
양쪽에 적용한 후 판매자 왼손/오른손 UF2를 각각 복사한다. 오른손은 다시 기존 Central로
사용한다. PC의 이전 페어링을 제거하고 `V&Z-Nano35`를 새로 페어링한다.
동글은 별도 보관한 **기존 Sofle 동글 UF2**로 복원하고 기존 Sofle을 다시 쓰려면 해당
Sofle 반쪽까지 본드 초기화/페어링한다. 신규 Nano Peripheral과 판매자 Central을 혼용하지 않는다.

현재 실기기 확인 완료/대기 상태는 [검증 기록](validation.md)을 참고하세요.
