# 현재 검증 상태

2026-10-31 로컬 빌드/소프트웨어 검사 기준이다.

| 항목 | 상태 |
|---|---|
| 기본 동글·좌·우·초기화·OLED·Studio 6개 타깃 | 로컬 빌드 및 생성 DTS/Kconfig/UF2 검사 통과 |
| 토템 원본 140개 바인딩·46개 콤보 | 35키 변환 대조 통과 |
| Keyball 모드 105개 바인딩·3개 매크로 | 원본 및 생성 DTS 대조 통과 |
| 새 트랙볼 처리 C + 고정 ZMK listener | ARM 에뮬레이션 16,388개 signed 축 검사 및 모드/버튼 검사 통과 |
| 기본 동글 연결·USB | 사용자 실기기 확인 완료 |
| OLED 복구 | 사용자 실기기 확인 완료 |
| 새 Mouse/Scroll/Snipe | 실기기 방향·감도·타이머·동시 입력 확인 대기 |
| GitHub Actions | 업로드 후 실행 확인 필요 |

빌드 성공은 실기기 동작 확인과 다르다. ARM 검사의 커널·레이어·최종 HID API는 테스트 더블이며
실제 USB/BLE, 타이머 경과, 이벤트 경합은 보증하지 않는다. 이전 호스트 GCC/UBSan 기반
`test-motion.py`는 이번 Windows 실행에서 재실행하지 않았다.

검사 스크립트는 `scripts/`, 테스트 입력은 `tests/`에 있다.
과거 상세 로그와 로컬 경로가 포함된 기록은 로컬 `docs/archive/`에 보관하며 Git에서 제외한다.
새 모드 실물 확인 항목은 [트랙볼 안내](trackball-modes.md)를 참고한다.
