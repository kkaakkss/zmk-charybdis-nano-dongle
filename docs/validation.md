# 현재 검증 상태

## 2026-11-03: FASTER/SNIPE 발동 교체와 전용 배율

MOUSE 3번=FASTER 홀드, 2+3=SNIPE 홀드로 교체했다.
FASTER의 1/21은 전용 ±10%p 배율이며 일반 배율을 변경하지 않는다.
실제 C ARM 검사에서 전용 20–200% 경계, 버튼 해제 무동작, 음수 소수 누적,
일반 이동의 불변성과 SNIPE 콤보 두 해제 순서를 통과했다.
실기기 콤보 타이밍과 속도 감각 확인은 대기 중이다.


## 2026-11-03: FASTER 홀드 모드

L4 2+3의 80ms 콤보로 L7 FASTER를 홀드한다. 실제 포인터 C 검사에서
일반 배율×1.5, 기존 가속 곡선, 음수/소수 이동, 스크롤 독립성과 해제 후 복귀를 통과했다.
고정 ZMK의 실제 콤보 해제 함수도 두 가지 해제 순서에서 1회만 해제하는지 검사한다.
생성 DTS에서 35키 L7, 콤보 범위·겹침과 momentary 바인딩을 확인한다.
커널·계층 전환 API는 테스트 더블이며 실제 2/3 단독·동시 입력 감각은 실기기 확인 대기다.


## 2026-11-03: L5/L6 감속 위치 통일과 Excel 수정키

L5와 L6의 감속을 11→21번으로 옮기고 11번을 왼쪽 Shift로 통일했다.
L5 3번은 왼쪽 Ctrl+Shift 동시 홀드다. 생성 DTS에서 두 레이어의 위치/키코드와
수정키 바인딩을 검사한다. 실제 키 해제와 Excel 가로 스크롤은 실기기 확인 대기다.


## 2026-11-03: Move/Scroll/Snipe 독립 속도

L4 11=Shift, 21=이동 감속. L5와 L6는 각각 1/11에 독립적인 ±10%p 배율을 둔다.
실제 C ARM 검사에서 세 모드 배율 독립성, 20–200% 경계, 음수·소수 누적,
기존 가속과 원시 자동 Mouse 임계값 및 레이어 간 배율 유지를 통과했다.
센서 400 CPI는 유지한다. 실기기 입력/속도 감각과 앱 호환성은 확인 대기다.


## 2026-11-03: OSL F13–F17 / GUI+Tab

## 2026-11-03: 완료 알림 20초 점멸

## 2026-11-03: 타이머 실행 중 OLED 유지

커널·큐·디스플레이는 테스트 더블이며 실물 동작은 확인 대기다.

## 2026-11-01: OLED 오른쪽 끝열 잔점 대응

사용자 최신 `display-name`은 유지하고 `segment-offset`만1→2로 조정했다.
고정 Zephyr 실제 SH1106 쓰기 함수의 ARM 검사에서 표준 중앙128열 패널 가정하에
offset1의 끝열 미갱신과offset2의 전체·마지막 픽셀 부분 갱신을 재현/검증했다.
기존 OLED 버퍼 정지·초기화 검사도 통과했다. 버스/RAM은 테스트 더블이므로
사용자가 새 펌웨어에서 오른쪽 흰 점이 사라졌음을 확인했다.
[끝열 분석](oled-edge-pixels.md)을 참고한다.

## 2026-11-01: 직장용 단발 프리셋 타이머로 변경

현재 기능은 OSL J/K/L의 5/10/25분 새 시작과 OSL ;의 즉시 종료뿐이다.
이전 자동 집중/휴식 반복·회차·일시정지와 타이머 콤보는 제거했다.
DONE과 단색 축하 그림, 전체 UI 10초 점멸 및 60초 추가 유지 후 자동 숨김을 적용한다.
실제 C의 ARM 검사는 세 프리셋 2,400초 진행, 즉시 교체/재시작/종료,
20개 점멸 반주기와 10초/70초 경계, 알림 중 키 입력/유휴 전환/취소/재시작,
이전 콜백의 지연 도착을 검사한다. GitHub는 같은 C를 호스트 GCC+UBSan으로 검사한다.
실제 빌드/실행 결과는 해당 커밋의 Actions를 참고한다. 실물 렌더링·점멸·입력은 별도 확인 대상이다.
현재 조작은 [타이머 안내](pomodoro.md)를 따른다.

## 2026-11-01: 포인터 가속·OLED 유휴 시간

- 센서 400 CPI를 유지하고 일반 이동에만 1–1.75배 시간 기반 가속을 추가했다.
- OLED 유휴 시간은 300000ms(5분)이며 contrast 128은 유지한다.
- 실제 처리기와 고정 ZMK listener를 사용하는 ARM 회귀 검사를 통과했다.
  기존 16,388개 signed 축 검사와 모드/버튼/잔여 이동 검사에 더해,
  느린 1배·빠른 최대 배율, XY 공통 배율, 원시 자동 Mouse 임계값, 100ms 재시작,
  보고 주기 변화, uptime wrap, 같은 시각의 BLE 묶음, 단일 축 sync를 확인했다.
- GitHub OLED 빌드에는 같은 회귀 검사를 호스트 GCC+UBSan으로 실행하는 단계를 추가했다.
  각 커밋의 실제 빌드·CI 결과는 GitHub Actions에서 확인한다.
- 가속 손맛, 실제 5분 화면 꺼짐과 입력 후 복귀, USB/BLE 동시 사용은 실기기 확인 대기다.
- 이 가속 단계에서는 OLED 타이머를 검토만 했다. 이후 구현은 위 뽀모도로 기록을 참고한다.

빌드 성공은 실기기 동작 확인과 다르다. ARM 검사의 커널·레이어·최종 HID API는 테스트 더블이며
실제 USB/BLE, 타이머 경과, 이벤트 경합은 보증하지 않는다. 이전 호스트 GCC/UBSan 기반
`test-motion.py`는 이번 Windows 실행에서 재실행하지 않았다.

검사 스크립트는 `scripts/`, 테스트 입력은 `tests/`에 있다.
과거 상세 로그와 로컬 경로가 포함된 기록은 로컬 `docs/archive/`에 보관하며 Git에서 제외한다.
새 모드 실물 확인 항목은 [트랙볼 안내](trackball-modes.md)를 참고한다.
