# OLED 끝열의 흰 점 — 2026-11-01

사용자 사진에서 배터리·봉고캣 옆의 오른쪽 한 열에 분리된 흰 점이 반복된다.
이 점들을 상태 정보로 표시하는 코드는 없다. 초기 타이머의 회차 점은 왼쪽 여백에 있었고,
현재 프리셋 타이머에서는 제거됐다. 사진의 점은 타이머 추가 전 사진에도 보였다.

## 유력한 원인과 변경

기존 Sofle 설정은 폭 129, `segment-offset=1`이었다. OLED/USB 복구 때 폭을 128로
바꾸면서 시작 열 1은 유지했다. SH1106는 RAM 폭이 132이며 일반적인 중앙 128열 패널은
RAM 열 2–129를 표시한다. 이 패널에서 폭128/시작열1이면 1–128만 쓰므로,
보이는 마지막 열129에는 갱신하지 않은 RAM 값이 남을 수 있다.

`segment-offset`을 **1 → 2**로 바꿔 전체 128열을 2–129에 기록하도록 맞췄다.
논리 크기128×64, 1비트 전체 버퍼, 전용 UI 작업 큐, 배터리·봉고캣·타이머·사용자 레이어 이름은 유지한다.
화면 폭을 다시129로 늘리거나 특정 픽셀/아이콘을 가리는 방법은 사용하지 않는다.

이는 사진·기존 설정·드라이버로부터의 추정이다. 해당 실물 패널의 배선을 계측하거나
RAM을 읽은 것은 아니므로, 표준 중앙128열 배치에 대한 이 수정이 실제 점을 없애는지는 실물 확인이 필요하다.

## 검증

`scripts/test-display.py`에 고정 Zephyr의 실제 `ssd1306_write_sh1106()` 함수를 추가했다.
버스와 8페이지×132열 RAM은 테스트 더블이다. 표준 가시 영역2–129를 가정하여:

- offset1에서 마지막 열의 네 점이 그대로 남는 경로를 재현한다.
- offset2에서 1024바이트 전체 프레임이 가시128열을 모두 갱신함을 검사한다.
- 논리 x=127의 부분 갱신이 실제 마지막 열129에 기록되는지 검사한다.
- 기존 LVGL 0행 정지/수정버퍼1024개 크기 조합과 위젯 초기화 검사도 유지한다.
- 생성 DTS 검사에서128×64와offset2를 확인한다.

새 동글 OLED UF2로 갱신한 뒤 USB 전원을 완전히 분리했다가 연결하여 점·좌우 잘림·
배터리·봉고캣·긴 레이어 이름·타이머 점멸/복귀를 확인한다. 좌우 펌웨어나 본드 초기화는 필요 없다.

근거: [Zephyr SH1106 바인딩](https://docs.zephyrproject.org/latest/build/dts/api/bindings/display/sinowealth,sh1106-i2c.html)의
132열 컨트롤러와 시작 열 정의, [Adafruit 공식 SH1106G 드라이버](https://github.com/adafruit/Adafruit_SH110x/blob/master/Adafruit_SH1106G.cpp)의 시작 오프셋2.
