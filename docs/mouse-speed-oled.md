# MOUSE 속도 버튼과 OLED 정리

위치 번호는 ZMK의 0–34 인덱스다.

| MOUSE 위치 | 기능 |
|---|---|
| 1 | 이동 배율 +5%p (Ctrl 홀드: Ctrl+W) |
| 11 | 왼쪽 Shift (Alt 홀드: 뒤로) |
| 21 | 이동 배율 -5%p |
| 32 | 탭 Space 후 BASE / 홀드 L1 / 해제 BASE |
| 11+12+13 | MOUSE를 종료하고 일회성 OSL 활성화 |

배율은 기본 100%, 범위 20–200%이며 버튼을 누를 때마다 한 단계 변경한다.
센서의 하드웨어 400 CPI는 바꾸지 않는다. 일반 이동에 기존 1–1.75배 가속과
사용자 배율을 함께 적용하며, 원시 입력 기준 가속·자동 Mouse 임계값은 유지한다.
L5의 1/21은 스크롤 배율 +5%p/-5%p, L6의 1/21은 SNIPE 배율 +5%p/-5%p다.
L4/L5/L6 모두 11번은 왼쪽 Shift다.
일반 이동·스크롤·SNIPE는 각각 별도 배율을 가지며, 모두 기본 100%, 범위 20–200%다.
스크롤은 기존 1/8을 기준으로, SNIPE는 기존 1/4를 기준으로 배율을 적용한다.
세 배율 모두 레이어 전환 중 유지하며 동글 재시작 때 100%로 복귀한다.
작은 움직임의 소수 부분은 축별로 누적하고 배율/모드 변경 시 남은 소수값은 비운다.
배율은 레이어 전환 중 유지되고 동글 재시작 때 100%로 돌아온다. Flash 저장은 하지 않는다.

OSL(3)은 MOUSE(4)보다 낮으므로 단순 `&sl 3`만으로는 MOUSE를 덮지 못한다.
콤보는 먼저 BASE로 복귀하고 기존과 같은 `&sl 3`을 실행한다.
기존 BASE의 11+12+13 콤보는 변경하지 않는다.

배터리는 `L59%`, `R100%`처럼 표시한다. BLE source 번호는 좌우가 아닌
저장된 본드 슬롯이므로 키의 실제 위치와 출처를 통해 좌우를 식별한다.
전원 켠 직후 식별 전에는 `?`이며, 일반 키를 한 번 누르면 L/R을 알 수 있다.
식별 후 행 순서는 L 위 / R 아래로 고정한다. 라벨과 배터리 아이콘을 함께 이동한다. 좌우 이벤트가 한 화면 갱신에 합쳐져도
양쪽의 최신 배터리 캐시를 모두 그린다.

잠금은 켜진 항목만 `N`(Num), `C`(Caps), `S`(Scroll) 순서로 표시하며,
모두 꺼지면 빈칸이다. `LCK`와 CPM은 표시하지 않는다.
봉고캣 애니메이션용 내부 WPM 계산과 타이머 기능은 유지한다.

동글 OLED UF2만 갱신한다. 빌드와 소프트웨어 검사는 실제 배율 감각,
콤보 타이밍, 좌우 표시, USB 연결 및 타이머 알림의 실기기 검증을 대신하지 않는다.

연결 시 전달되는 키 개수는 물리적인 18/17개가 아닌 공통 `ZMK_KEYMAP_LEN=35`이므로
그 값만으로는 좌우를 식별하지 못한다. 식별 전에는 ?가 표시된다.

## Excel 가로 스크롤

Windows Excel은 Ctrl+Shift를 누른 채 세로 휠을 굴리는 가로 스크롤을 공식 지원한다.
https://support.microsoft.com/en-us/excel/move-or-scroll-through-a-worksheet
Excel 버전과 환경에서 실제 동작을 확인해야 한다. 별도 PC 프로그램은 설치하지 않는다.
L5 3번은 왼쪽 Ctrl+Shift 동시 홀드다 (`&kp LC(LSHIFT)`).
3번을 누른 채 트랙볼을 위아래로 굴려 Excel 가로 스크롤을 사용하고, 놓으면 두 수정키를 해제한다.

## FASTER (L7)와 SNIPE 발동

MOUSE(L4)에서 2번 단독 홀드는 SCROL, 3번 단독 홀드는 FASTER다.
위치 2+3을 80ms 안에 함께 누르면 SNIPE가 켜진다.
둘 중 하나를 놓으면 SNIPE가 해제되고 나머지 키 해제도 콤보가 소비한다.
콤보 판정 때문에 단독 2/3의 전환이 최대 80ms 지연될 수 있다.
L5 3번의 Excel용 Ctrl+Shift는 유지한다.

FASTER 1/21은 전용 배율을 +5%p/-5%p 조절한다. 기본 100%, 범위 20–200%이며
일반/Scroll/Snipe의 배율을 변경하지 않는다. 동글 재시작 시 100%로 돌아온다.
실제 FASTER 이동 = 현재 일반 이동 배율 × 기존 가속 곡선 × 1.5 × FASTER 전용 배율이다.
기본 전용 배율 100%에서 일반 이동의 1.5배다. OLED에는 FASTER를 표시한다.

센서 400 CPI는 유지한다. 움직이는 동안 일반 자동 Mouse 30초 타이머를 갱신한다.
기존 자동 Mouse가 장시간 무입력으로 만료되면 홀드 해제 시 BASE의 일반 포인터 이동으로
돌아갈 수 있다. 실제 단독/콤보 입력 감각과 속도는 실기기에서 확인한다.
