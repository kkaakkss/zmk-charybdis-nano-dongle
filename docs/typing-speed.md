# OLED 타수 표시

배터리 왼쪽에 `CPM`과 숫자를 두 줄로 표시한다. 위치 x=38, y=0,
영역 36×18픽셀을 사용해 네 자리 숫자가 배터리·타이머와 겹치지 않게 한다.

CPM은 기존 ZMK WPM × 5로 환산한 **분당 타수 추정치**다.
고정 ZMK 소스는 키코드 해제 이벤트를 세고, 1초마다 갱신하며 5초마다
측정 구간을 다시 시작한다. 한글 조합이나 타자시험 점수를 계산하지 않는다.
콤보·매크로 등도 결과에 영향을 줄 수 있다. 표시 범위는 0–1275다.

봉고캣이 사용하던 WPM 이벤트를 재사용하고 OLED 표시 큐에서 갱신한다.
키맵·레이어 display-name·타이머 조작은 유지한다. 설치는 동글 OLED UF2만 갱신한다.
실제 표시·정렬·USB 동작은 실기기 확인 대상이다.
